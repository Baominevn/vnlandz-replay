REST API SPEC

1. Client Poll Lệnh Từ Server:

Minecraft Client gửi GET định kỳ 1s để nhận lệnh thực thi:

GET /poll?clientKey=TEN_KEY
// Response: { "ok": true, "command": "/say Hello" }

2. Client Bắn Sự Kiện Sang Discord:

Gửi POST khi có Chat, Replay hoặc sự kiện:

POST /events?clientKey=TEN_KEY
Content-Type: application/json
{ "type": "CHAT", "player": "Steve", "server": "mc.hypixel.net", "message": "Hello Discord!" }
PROJECT: mc-replay-discord-bridge
ENV: production
